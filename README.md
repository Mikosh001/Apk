# Профессия 2.0 — Цифрлық кадровый резерв үшін MVP

Бұл репозиторий "Профессия 2.0" agri-tech upskilling платформасының толық стек MVP-н қамтиды.

## Құрылым

- `backend/` — Node.js + Express + Prisma REST API
- `frontend/` — React + Vite клиенті (TypeScript)
- `docker-compose.yml` — PostgreSQL мәліметтер базасын іске қосу

## Алдын ала талаптар

- Node.js 20+
- npm 10+
- Docker & Docker Compose

## Орнату қадамдары

```bash
# тәуелділіктерді орнату
cd backend
npm install

cd ../frontend
npm install

# PostgreSQL контейнерін іске қосу
cd ..
docker-compose up -d

# дерекқор миграциялары мен бастапқы деректер
cd backend
npx prisma migrate dev
npx prisma db seed

# сервистерді дамыту режимінде іске қосу
npm run dev # backend ішінде

cd ../frontend
npm run dev
```

## Орта айнымалылары

`.env.example` файлдарын `backend/` және `frontend/` бумаларында қараңыз. Негізгілері:

- `DATABASE_URL`
- `JWT_SECRET`
- `FRONTEND_URL`
- `VITE_API_URL`

## Негізгі мүмкіндіктер

- Email/құпиясөз аутентификациясы (JWT)
- Курстар, сабақтар және адаптив тесттер (қиындықты тармақтау)
- Тест нәтижесіне сәйкес бейдждер мен ұсынылатын ремедиация
- Портфолио және QR-кодпен бөлісу
- Вакансиялар және студентке сәйкес келтіру алгоритмі
- Жұмыс берушілерге арналған вакансия басқару
- Әкімші панелі — курстар мен сұрақтарды CRUD
- Дрон маршрутының қарапайым симуляторы

## Құжаттама

- OpenAPI сипаттамасы: `backend/openapi.json`

## Линт және форматтау

- `npm run lint` командалары арқылы тексеруге болады (әр қосымша ішінде)
- `.prettierrc` форматтау ережелері ортақ

## Docker

`backend/Dockerfile` API қызметін контейнерлеуге арналған. `docker-compose.yml` Postgres-ті ғана қамтиды.

## Тестілеу есептемесі

Ағымдағы ортада автоматты тесттер іске қосылмады. Қолданбаны жергілікті машинада жоғарыдағы нұсқаулық бойынша тексеріңіз.
